🚀 פתח את האפליקציה

🎭 מהי האפליקציה?

מטפורות בהוראה היא כלי אינטראקטיבי לניתוח מטפורות מעולם ההוראה. בכל פעם תבחרו מטפורה אחת — מטפורת המורה, התלמיד, תהליך הלמידה, השכל או הזהות המקצועית — ותעברו תהליך ניתוח שיטתי בן 7 שלבים: מזיהוי המטפורה, דרך בניית פרומפט ויצירת תמונה ב-AI, ועד רפלקציה וסיכום.

📐 שלבי העבודה

1
רקע תיאורטי

הכרות עם תורת המטפורה המושגית, קריאת מאמר אקדמי, ומבחן קצר. הבסיס התיאורטי שילווה אתכם לאורך כל התהליך.

2
בחירת מטפורה וחשיפתה

בחרו נושא מעולם ההוראה, זהו מטפורה ספציפית, והגדירו תחום מקור (Source), תחום יעד (Target), ומיפויים ביניהם.

3
בניית פרומפט

תרגמו את הניתוח המטפורי להנחיה לכלי AI: סגנון אמנותי, סצנה, צבעים, אווירה — ככל שההנחיה מדויקת יותר, כך התמונה תשקף טוב יותר את הפרשנות שלכם.

4
תמונה ראשונית

צרו תמונה בכלי AI (Gemini, ChatGPT וכד׳), העלו אותה לאפליקציה, ותארו: מה רואים? מה מרגישים? מה הפתיע?

5
פרשנות ויצירה מחודשת

קבלו משוב, שנו את הפרומפט לאור ההתבוננות, וצרו תמונה מתוקנת. השוו בין שתי התמונות.

6
רפלקציה

חשבו על התהליך: מה למדתם על המטפורה? כיצד ה-AI תפקד ככלי פרשני? מה הייתם עושים אחרת?

7
סיכום וייצוא

צפו בסיכום העבודה, בדקו שלמות, וייצאו PDF + JSON להגשה.

❓ שאלות נפוצות

מה זה קובץ JSON ולמה צריך אותו?

קובץ JSON הוא ארגז שבו ארוזה כל העבודה שלכם. הוא מאפשר למרצה לבדוק את העבודה בכלי אוטומטי. אין צורך לפתוח אותו — רק להעלות ל-Moodle.

שכחתי לשמור ויצאתי — אבדו הנתונים?

לא! האפליקציה שומרת אוטומטית בדפדפן. פתחו שוב את אותו דפדפן באותו מחשב.

עברתי מחשב — מה עושים?

לפני שמחליפים מחשב, הורידו גיבוי JSON. במחשב החדש — פתחו את האפליקציה ולחצו ייבוא JSON כדי לטעון את העבודה.

הקובץ JSON נראה כמו "קוד" — תקין?

כן! זה בדיוק איך שקובץ JSON נראה. סגרו והעלו אותו כמו שהוא.
