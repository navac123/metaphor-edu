💾 גיבוי JSON

מה זה JSON?

ארגז שבו ארוזה כל העבודה שלכם — כל מה שכתבתם, בחרתם והעליתם. אין צורך לפתוח אותו — רק להעלות ל-Moodle. אם תפתחו בטעות ותראו "קוד" — זה תקין!

❓ שאלות נפוצות

שכחתי להזין שם — מה עושים?

חזרו לאפליקציה, מלאו שם בסרגל הצד, ולחצו "גיבוי JSON" שוב. הקובץ החדש יכיל את השם.

עברתי מחשב ואין לי את הנתונים?

אם הורדתם גיבוי JSON קודם — פתחו את האפליקציה, לחצו "ייבוא גיבוי", וטענו את הקובץ.

Moodle לא מקבל את הקובץ?

בדקו שגודל הקובץ מתחת ל-5MB. אם גדול — נסו להשתמש בתמונות קטנות יותר.

פתחתי את ה-JSON ונבהלתי מ"קוד"

הכל תקין! ככה JSON נראה. סגרו והעלו אותו כמו שהוא.
